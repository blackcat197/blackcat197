Установка приложения

Рабочие часы работает как PWA — устанавливается на любое устройство прямо из браузера, без App Store

https://htmlpreview.github.io/?https://gist.github.com/blackcat197/da6e67895984fd4cf2d15cdd15c2ab74/raw/index.html
🍎
iPhone / iPad
Safari — обязательно
1
Скопируйте ссылку выше и откройте в Safari (не Chrome, не Brave)
2
Нажмите кнопку Поделиться ↑ внизу экрана по центру
3
Прокрутите список вниз → выберите На экран Домой
4
Нажмите Добавить — иконка появится на рабочем столе
✓ Работает без интернета
🤖
Android
Chrome — рекомендуется
1
Откройте ссылку в Chrome
2
Нажмите ⋮ три точки в правом верхнем углу
3
Выберите Добавить на гл. экран или Установить приложение
4
Нажмите Установить — готово
✓ Уведомления работают
💻
Mac
Safari или Chrome
1
Откройте ссылку в Chrome или Safari
2
Chrome: нажмите значок ⊕ в адресной строке справа → Установить
3
Safari: меню Файл → Добавить в Dock
4
Приложение появится в Launchpad и Dock
✓ Открывается как отдельное окно
🪟
Windows
Chrome или Edge
1
Откройте ссылку в Chrome или Microsoft Edge
2
В адресной строке справа появится значок ⊕ — нажмите его
3
Нажмите Установить в появившемся окне
4
Ярлык появится на рабочем столе и в меню Пуск
✓ Работает без браузера
💡
Данные хранятся на устройстве — сделайте резервную копию в настройках приложения ⚙️ → Резервная копия → Сохранить копию, чтобы не потерять данные при очистке браузера.
