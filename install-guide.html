Installation guide

Work Hours runs as a PWA — install on any device directly from the browser, no App Store needed

https://htmlpreview.github.io/?https://gist.github.com/blackcat197/da6e67895984fd4cf2d15cdd15c2ab74/raw/index.html
🍎
iPhone / iPad
Safari — required
1
Copy the link above and open it in Safari (not Chrome, not Brave)
2
Tap the Share button ↑ at the bottom center of the screen
3
Scroll down → select Add to Home Screen
4
Tap Add — the icon will appear on your home screen
✓ Works offline
🤖
Android
Chrome — recommended
1
Open the link in Chrome
2
Tap ⋮ three dots in the top right corner
3
Select Add to Home screen or Install app
4
Tap Install — done
✓ Notifications work
💻
Mac
Safari or Chrome
1
Open the link in Chrome or Safari
2
Chrome: click the ⊕ icon in the address bar → Install
3
Safari: go to File menu → Add to Dock
4
The app will appear in Launchpad and the Dock
✓ Opens as a separate window
🪟
Windows
Chrome or Edge
1
Open the link in Chrome or Microsoft Edge
2
An ⊕ icon will appear in the address bar — click it
3
Click Install in the popup window
4
A shortcut will appear on the desktop and in the Start menu
✓ Works without a browser
💡
Data is stored on your device — back up in the app settings ⚙️ → Backup → Save backup to avoid losing data if the browser cache is cleared.
